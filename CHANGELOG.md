
# Changelog

All notable changes to the Apex Shader Ecosystem are documented here.

## [0.1.0] - 2026-08-05

### Added

- Clean-room Apex shader monorepo.
- Independent Core, SpectraOverdrive, Integrations, Avatar, World, Water, Fog, FX, Screens, Toon, Tools, and Examples packages.
- Handwritten Unity Built-in Render Pipeline vertex/fragment shader foundations.
- iOS, Android, Quest, and PCVR platform design rules.
- Static repository validation and release archive tooling.
- Stable Unity metadata GUID generation.
- Importable quick-start materials for the included shaders.
