
# Apex Quick Start Materials

These materials point at the baseline shaders included in Apex 0.2.0. Drop them onto suitable meshes, then assign textures and tune properties in the Inspector.

They are configuration samples, not proof that every target platform has completed runtime validation.

Apex custom avatar materials are intended for PC. Generate a separate SDK mobile material through **Apex > Mobile Avatar Fallback Builder** before Android, Quest, or iOS avatar uploads.
