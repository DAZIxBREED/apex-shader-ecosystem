
# Apex Quick Start Materials

These materials point at the baseline shaders included in Apex 0.3.0. Drop them onto suitable meshes, then assign textures and tune properties in the Inspector.

They are configuration samples, not proof that every target platform has completed runtime validation.

Apex custom avatar materials are intended for PC. Generate a separate SDK mobile material through **Apex > Mobile Avatar Fallback Builder** before Android, Quest, or iOS avatar uploads.

Included 0.3.0 additions:

- **Apex World Vertex Blend Lite** — paint vertex red from Layer A to Layer B.
- **Apex Water Opaque Mobile** — opaque headset/phone-friendly water baseline.
- **Apex FX Dissolve Cutout** — lit cutout dissolve with emissive edge.
- **Apex Screens LED Panel Lite** — procedural LED aperture and RGB subpixel screen.
