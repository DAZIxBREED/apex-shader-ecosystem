# Apex Screens — Project Workup

## 0.3.0 implementation

- `Apex/Screens/VideoPanelLite`: one-sampler `_MainTex` video panel with crop/flip, grading, scanlines, vignette, fog, and SpectraOverdrive.
- `Apex/Screens/LEDPanelLite`: one-sampler quantized LED panel with configurable pixel count, gap/aperture, procedural RGB subpixels, grading, and Spectra response.
